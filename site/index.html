Camera
Smoother

Even out the pace of a camera move while keeping its path.

Trim the setup and tail, smooth pans and slides, and compare captured and interpolated frames in a local preview. Your original stays read-only. All footage processing runs on your Mac.

Install

Requires an Apple silicon Mac with Git and Homebrew. The installer sets up the CLI, dependencies and your chosen agent skill.

Read the installer ↗

Codex

installer=$(curl -fsSL https://raw.githubusercontent.com/jenny-Media/camera-smoother/v0.1.0/install.sh) && bash -c "$installer" -- codex

Claude Code

installer=$(curl -fsSL https://raw.githubusercontent.com/jenny-Media/camera-smoother/v0.1.0/install.sh) && bash -c "$installer" -- claude

Run the command in Terminal, then start a new agent session. Ask it to use camera-move-smoothing on a local clip. Use both or cli in place of the agent name to install both skills or just the CLI.

From clip to export

  1. Analyze a move

    Track camera movement, choose trim points and flag cuts or stretches with uncertain motion.

  2. Compare the timing

    Review the original, captured-frame retime and optional interpolation on the same playhead.

  3. Keep the edit

    Export a silent H.264 MP4 at source resolution and frame rate by default. ProRes 422 is available.
