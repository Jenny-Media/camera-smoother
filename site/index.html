Camera Smoother

Even out the speed of pans, slides, and push-ins.

Install or update

Run on an Apple silicon Mac with Git and Homebrew. This installs the CLI and skills for Codex and Claude Code.

installer=$(curl -fsSL https://smooth.jenny.media/install.sh) && bash -c "$installer"

Analyze, render, and preview

Choose a local clip. Replace JOB_ID with the ID from analyze. The source stays read-only.

CS="$HOME/.local/share/camera-smoother/camera-smoother"
"$CS" analyze "/absolute/path/to/clip.mp4"
"$CS" render --job JOB_ID
"$CS" serve --job JOB_ID

Open the preview URL printed by serve. On render, use --preset apple-playback for HEVC, --preset editing for ProRes, or --preset share for a smaller MP4.
