Camera Smoother

Even out the speed of pans, slides, and push-ins.

Prompt for your agent

Read https://smooth.jenny.media/agent.md, install Camera Smoother if needed, and help me smooth a local clip I choose.

Install in Terminal

Requires an Apple silicon Mac with Git and Homebrew.

installer=$(curl -fsSL https://smooth.jenny.media/install.sh) && bash -c "$installer"

How it works

Camera Smoother follows visual features from frame to frame and adjusts the timing where it can measure the move reliably. It preserves the camera path and saves a separate video on your Mac.
